Singular Value Decomposition

The math behind image compression and PCA.

The project as a whole is to be read as demonstration of singular value decomposition (SVD)
The following are the features of the project:

  • A function from scratch as well as NumPy routine to find SVD of a matrix.
  • Demonstration of application of SVD to image compression.
  • A custom binary format (.svd) to store the compressed image.
  • Demonstration of application of SVD to principal component analysis (PCA).
  • An interactive streamlit app (SVD Lab) to explore the applications demonstrated.
